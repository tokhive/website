# TokHive

TokHive is an open marketplace for AI tokens. It connects people with unused ChatGPT or Claude subscription capacity to buyers who want first-party model access at a lower cost. Providers earn from spare capacity, and buyers use familiar APIs with a TokHive API key.

## Features

- **First-party models:** requests are served through providers' OpenAI and Anthropic subscriptions.
- **Familiar APIs:** supports OpenAI Responses, Chat Completions, and Anthropic Messages.
- **Provider control:** providers run the open-source [Bee](https://github.com/tokhive/bee) agent on their own machines and choose when to share capacity.
- **TEE-backed execution:** provider credentials are sealed to a [Trusted Execution Environment](https://github.com/tokhive/tee), and successful calls produce signed usage receipts for settlement.

This repository contains the TokHive website, published at [tokhive.ai](https://tokhive.ai).
